# The car radio

Put your own audio files in this folder (`.mp3`, `.m4a`, `.aac`, `.ogg`, `.opus`, `.wav`, `.flac`) and the car radio plays them.
Nothing here is committed to git: the songs stay on this computer.

- The radio plays while you are in a car, and in the bars. It picks up where it left off when you get back in.
- `N` next song, `B` the one before, `V` radio off / on.
- Settings (`Esc`) has the radio's volume.
- The name shown on screen is the file's name, without a leading track number: `03 - Song Name.mp3` shows as "Song Name".
  A file named `Artist - Song Name.mp3` shows both.
- Songs play in the order of their file names, starting from a different one each time.
